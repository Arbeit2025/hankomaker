# hankomaker（はんこメーカー）

入力した文字や絵文字を、印鑑の捺印みたいな画像にして PNG で保存できる小さなWebツールです。

## できること

- 形の選択：丸（外側の太い輪＋内側の細い輪の二重リング）／角（四角い枠）
- インクの色：朱（デフォルト）／黒／藍
- 背景：透明／白
- 文字数に合わせた自動レイアウト
  - 1文字：大きく中央に
  - 2文字：縦に2つ並べる（苗字のはんこ風）
  - 3〜4文字：2×2のグリッド
  - 5文字以上：横一列に縮めて収める
- 捺印らしく、全体を少し傾け、インクのかすれ（小さな抜け）を付ける
- できあがりを `hankomaker.png` としてダウンロード

## 仕組み

描画はすべてブラウザ側の HTML Canvas で行います。サーバーはページを返すだけで、入力した文字は送信も保存もされません。色絵文字や文字の字形は、閲覧している端末のフォントで描かれるため、端末によって見た目が少し変わります。

傾きとかすれの乱数は入力内容から決まるので、同じ文字・同じ設定では毎回同じ捺印になります。

## 技術

- Python / Flask の単一ファイルアプリ（app.py）。描画ロジックはページ内の JavaScript
- テスト: `python -m pytest tests/ -q`
- 起動: `gunicorn app:app`（Render想定）
